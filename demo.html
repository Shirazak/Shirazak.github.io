BundleDesk: SplitAPK Installer

Core feature walkthrough demonstrating how com.nativeinvaders.bundledesk uses REQUEST_INSTALL_PACKAGES strictly for user-initiated local package file management and installation.

Direct file: demo.mp4 Package ID: com.nativeinvaders.bundledesk

What This Video Demonstrates

  1. Launching BundleDesk: The user opens BundleDesk from Android and views the local package management dashboard.
  2. User-Initiated File Selection: The user taps to pick a local .apk, .apks, .xapk, .apkm, or .zip archive via Android's system file picker (Storage Access Framework). BundleDesk does not download or install apps automatically.
  3. Local Package & Split Inspection: BundleDesk reads the archive on-device to show matched ABI/density split APKs, compatibility status, and SHA-256 digest before installation.
  4. Native Android PackageInstaller Flow: When the user explicitly taps Install, BundleDesk checks canRequestPackageInstalls() (guiding the user to Android's Install unknown apps setting if needed) and hands the selected package stream to Android's native PackageInstaller system confirmation dialog.
